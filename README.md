### 👋 About me

I'm a **Cloud Engineer at IThinkUPC** based in Barcelona, working on multi-cloud infrastructure (AWS, Azure) for 130+ government, enterprise and NGO clients.

- ☁️ Architecting and operating secure, compliant AWS landing zones (Organizations, IAM, VPC, EC2, S3, Lambda, WAF, GuardDuty, KMS, CloudWatch)
- 🏗️ Standardizing deployments with **Terraform + Packer** — 15+ reusable modules, ENS compliance across environments
- 🤖 Exploring the infrastructure layer of **LLMOps**: Bedrock AgentCore, MCP, RAG, self-healing operations
- 🔄 Orchestrating centralized **GitHub Actions** pipelines with automated testing, security scans and seamless rollouts
- 🛠️ Building internal tooling in **Python** to abstract repetitive workflows and save the team hours every week

> [!NOTE]
> Most of my work in this account lives in **private organization repositories** (`@cloudserviceconsulting`, 🔒 members-only), so public activity underrepresents my day-to-day contributions. Widgets below show **aggregated counts only — no client code is exposed**.
